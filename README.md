## 📖 About This Application

**EAGLE** is a modern, responsive web application designed to empower users with an integrated scanning and analysis experience. Built using React and Vite, it allows users to scan items, analyze results, compare products, and manage a history of their activities. The interface is highly dynamic and user-centric, aimed at providing real-time data insights efficiently.

### Key Features
| Feature | Description |
|---------|-------------|
| 📷 **Scanner** | Advanced scanning functionality to capture product details instantly. |
| 📊 **Analysis** | Deep-dive analytics into scanned results and comprehensive reports. |
| ⚖️ **Comparison** | Compare multiple products side-by-side to make informed decisions. |
| 🕰️ **History & Reports**| Keep track of all previous scans and generate detailed insights. |
| 🗄️ **Database** | Manage product inventories and app settings seamlessly. |

## 🚀 Installation & Setup

To get a local copy up and running, please follow these simple steps:

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Setup Instructions

1. **Clone the repository** (if applicable) or navigate to the project directory:
   ```bash
   cd IQOO_Hackathon(EAGLE)
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```

4. **Open the application**:
   Open your browser and navigate to `http://localhost:5173/` (or the port specified in your terminal).
