# 📖 About EAGLE

**EAGLE** is an AI-powered product authenticity analysis application developed for the **iQOO Hackathon 2026**.

Counterfeit products can often look very similar to genuine products. EAGLE provides an additional layer of AI-assisted analysis by allowing users to scan a product using their smartphone camera and analyze multiple product signals.

The application can analyze:

* 📦 Product packaging
* 🦅 Brand/logo appearance
* 📝 Product text using OCR
* 🔳 QR codes
* 🏷️ Barcodes
* 🏭 Manufacturer information
* 📋 Product labels
* 🔍 Packaging characteristics
* 📊 Reference product information

EAGLE then compares the detected information with available reference data and generates a **confidence-based authenticity assessment**.

---

# 🎯 Problem Statement

Counterfeit products are becoming increasingly difficult to distinguish from genuine products because counterfeit packaging can closely imitate the original product.

Consumers may not have an easy way to check:

* Whether the packaging looks authentic
* Whether the logo matches
* Whether the barcode corresponds to the product
* Whether the QR code contains expected information
* Whether product information is consistent
* Whether the packaging differs from a known reference

EAGLE addresses this problem by combining multiple verification signals into one simple smartphone-based scanning experience.

# 🔬 How EAGLE Analyzes a Product

EAGLE does not rely on a single signal to determine authenticity.

Instead, it combines multiple available signals.

### 1. 📸 Image Capture

The user captures the product using a smartphone camera.

### 2. 📦 Packaging Detection

The system analyzes visible characteristics such as:

* Colors
* Layout
* Product name
* Label placement
* Typography
* Product graphics
* Nutrition/ingredient sections
* Manufacturer information

### 3. 🦅 Logo Analysis

The system identifies the visible brand/logo and compares available visual characteristics with reference information.

### 4. 📝 OCR

Important text can be extracted from the product image, including:

* Product name
* Brand
* Ingredients
* Manufacturer
* MRP
* Batch information
* Manufacturing information
* Expiry/best-before information
* Regulatory/license information where visible

### 5. 🔳 QR Analysis

If a QR code is detected, EAGLE extracts and analyzes the available QR information.

### 6. 🏷️ Barcode Analysis

The application attempts to detect supported product barcodes and compares the detected information with the reference product.

### 7. 🔎 Reference Comparison

The detected product information is compared with available reference product data.

### 8. 🤖 AI-Assisted Assessment

EAGLE combines the available signals and produces a confidence-based assessment.

---

# 📊 Verification Results

EAGLE provides four primary result categories:

### ✅ LIKELY GENUINE

The available signals show strong agreement with the reference information.

### ⚠️ SUSPICIOUS

One or more significant inconsistencies were detected.

### ❌ LIKELY COUNTERFEIT

Multiple important inconsistencies were detected across available signals.

### ❓ UNABLE TO VERIFY

There is insufficient information or reference data to make a reliable assessment.

---

# ⚠️ Important Note

EAGLE provides an **AI-assisted assessment**, not a legal guarantee of authenticity.

A product should not be considered legally genuine or counterfeit solely based on the EAGLE result.

For important, high-value, or safety-critical products, users should verify the product through the manufacturer's official verification channels.

## Prerequisites

Make sure the following are installed:

* [Node.js](https://nodejs.org/)

## 📥 Installation

Clone the repository:

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
```

Move into the project directory:

```bash
cd IQOO_Hackathon-EAGLE
```

Install dependencies:

```bash
npm install
```

EAGLE is designed with privacy in mind.

* Avoid collecting unnecessary personal information

* Protect API credentials
* Keep secrets out of frontend code
* Avoid automatically executing QR code content

# ⚠️ Limitations

EAGLE is an AI-assisted prototype.

Its analysis depends on:

* Image quality
* Lighting conditions
* Camera quality
* Available reference product information
* OCR accuracy
* QR/barcode readability
* Product database coverage
* AI analysis capabilities

A visual match alone cannot guarantee that a product is authentic.
